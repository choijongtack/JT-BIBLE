## 이슈 관찰
- 사용자 제보: AI 응답 내용은 "적용 단계로 넘어가겠습니다"처럼 전환되는데 Progress UI가 기대대로 따라가지 않음.
- 점검 파일:
  - `components/LearningSession.tsx`
  - `components/learning/ProgressTracker.tsx`
  - `hooks/useAIConversation.ts`

## 원인 정리
- 단계 상태(`currentStep`)는 `LearningSession.tsx`에서 정상적으로 변경될 수 있음.
- 그러나 AI 응답 파싱은 기본적으로 `[NEXT_STEP:STEP_NAME]` 태그 기반.
- AI가 태그 없이 자연어로만 단계 전환을 표현하는 경우, `stepChangedTo`가 설정되지 않아 UI 단계 표시가 이전 단계에 남을 수 있었음.

## 수정 내용
- 파일: `hooks/useAIConversation.ts`
- 변경:
  - `inferStepFromText(text)` 함수 추가.
  - `[NEXT_STEP:...]` 태그가 없는 경우에만 fallback으로 자연어 단계 전환 문구를 추론.
  - 전환 신호(예: 이제/다음/넘어가/전환/시작) + 단계 키워드(관찰/해석/적용/암송/시험/분석/이해)를 함께 만족할 때 `stepChangedTo` 설정.
- 안전장치:
  - 기존 태그 파싱 우선순위 유지(태그가 있으면 기존 로직 사용).
  - 태그 없는 응답에 한해 보완적으로 동작하도록 제한.
